# Wizard Bank

## Task

App for testing: [GlobalsQa](https://www.globalsqa.com/angularJs-protractor/BankingProject/#/login)

**This task** checks the following flow:

1. Sign in as a bank.
1. Add a client.
1. Go to the account opening page.
1. Select the added client and open their account in any currency.
1. Go back to the main page.
1. Sign in as the newly added client.
1. Add several deposit transactions.
1. Add several withdrawal transactions.
1. Go to the transaction history page (the browser should remain open).

The tests can be found in the `customerFlow.cy.js` file.
